# 🍽️ Divine Delights — Recipe Website

A multi-page **Cooking Recipes Website** built using **HTML5 and CSS3** as part of a Frontend Web Development assignment.  
This project focuses on creating a visually appealing, structured, and responsive recipe platform.

---

## 🌟 Features Implemented

### 🏠 Website Structure
- Multi-page website
- Home page with hero section
- Recipes listing page (All Recipes)
- Individual recipe pages (8 recipes)
- Consistent navigation bar across all pages
- Footer included throughout the website

---

### 🍲 Recipe System
Each recipe card includes:
- Recipe title
- Food image
- Short description
- Calories & cooking time
- Difficulty level (Easy / Medium / Hard)
- Likes (❤️ count)

Each recipe page contains:
- Full ingredients list
- Step-by-step instructions with images
- Preparation & cooking time table
- Nutrition facts section

---

### 🎨 CSS Styling & Design
- External stylesheet (`styles.css`)
- Warm **food-themed gradient backgrounds**
- Card-based UI layout
- Rounded corners and soft shadows
- Consistent spacing and alignment
- Typography styling for readability

---

### 📐 Layout Techniques
- Flexbox (navbar, card alignment, sections)
- CSS Grid (recipes layout)
- Proper use of margin, padding, and box model

---

### ✨ Interactive & Visual Effects
- Hover effects on recipe cards
- Gradient animated title text
- Smooth transitions and shadows
- Glowing particle/star background effect
- Scroll animations (desktop)
- Swipe-based scrolling (mobile)

---

### 📱 Responsiveness
- Mobile-friendly design using media queries
- Centered cards on smaller screens
- Horizontal swipe scroll for featured recipes
- Adaptive layout for different screen sizes

---

### 🔍 Bonus Features
- UI Search bar (visual only, no JavaScript)
- Parchment-style recipe page design
- Animated backgrounds and gradients
- Card hover elevation effects
